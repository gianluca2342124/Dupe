# Guía para vídeos de demostración

1. **Siempre resultados reales**: graba con el proveedor real activo, nunca con el catálogo DEMO (las alternativas demo son ficticias y llevan la etiqueta «DEMO»).
2. **Fecha visible**: el resultado muestra «comprobados hace …»; si el vídeo se publica días después, indica la fecha de grabación en el texto.
3. **Precio completo**: enseña el precio con envío si aparece; si pone «Envío no indicado», no lo ocultes.
4. **Etiquetas**: deja ver «Muy similar» / «Similar». No digas «idéntico» salvo que ponga «Mismo producto».
5. **Marcas**: muestra la tienda original solo para identificar el producto; no sugieras afiliación o respaldo de la marca.
6. **Grabación**: modo no molestar, brillo alto, zoom suave, dedo visible al escribir `gemelu.com/` (es el momento clave), duración 8–15 s.
7. **Publicidad**: si hay colaboración pagada, márcala (#publi / etiqueta de colaboración de la plataforma).
8. **Enlace**: en la bio, `gemelu.com/?utm_source=tiktok&utm_medium=social&utm_campaign=bio` (ver utm.md).
